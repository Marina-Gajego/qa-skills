# Labels by language

## Inside `.qa-skills/`: never translated
File names, section titles and sub-headings, header lines, the `Item` names in the Stack and Format tables, the `Goal` names in How to run, the `Principle` names in the OOP assessment, the verdict values (`consistent`, `mostly consistent with deviations`, `mixed`, `no clear structure`), session names and statuses (`done`, `pending`), table column names, suite names (`e2e`, `api`…), layout letters and the markers (`⚠️ UNCERTAIN`, `none found`, `n/a`, `(observed N/M)`, `(written: …)`, `(confirmed by QA)`, `❓`) stay in English in every language — other skills find them by these exact strings. Only the prose and the values written by you follow `report_language`.
