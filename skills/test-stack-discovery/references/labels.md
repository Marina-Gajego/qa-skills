# Labels by language

## Inside `test-stack.md`: never translated
Section titles, the header line, the `Item` names in the Stack table, the `Goal` names in How to run, the sub-headings under Patterns and conventions, and the markers (`⚠️ UNCERTAIN`, `none found`, `(observed N/M)`, `(confirmed by QA)`, `❓`) stay in English in every language — other skills find them by these exact strings. Only the prose and the values written by you follow `report_language`.
